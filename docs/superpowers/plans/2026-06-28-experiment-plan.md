### EXP-2: 배당 포함 vs 배당 제외 A/B 테스트
**가설:** 배당(morning_odds, morning_odds_rank)을 피처에서 제거하면 ROI가 오히려 올라간다.  
모델이 시장을 따라가지 않고 독자적인 패턴을 학습하면 시장 비효율을 발견할 수 있다.  
**방법:**
- 모델 A: 현재 피처 (배당 포함)
- 모델 B: morning_odds, morning_odds_rank 제외
- cold-start도 역배당 대신 field_avg로 변경

**비교 지표:** Top-1 정확도, Log Loss, 시뮬레이션 ROI  
**상태:** `[ ]`

### EXP-3: 조교 타임 피처 추가
**가설:** PDF에서 추출한 최근 조교 랩타임이 컨디션 대리 지표가 되어 예측력을 높인다.  
**피처:** `recent_workout_time` (최근 조교 1000m 기준 초), `workout_rank` (파트너 대비 순위)  
**방법:** PDF 파서 확장 → 조교 타임 DB 저장 → 피처에 추가 → 재훈련  
**상태:** `[ ]`

### EXP-4: 건강 이상 기록 피처 추가

**피처:** `injury_count_30d` (최근 30일 내 이상 기록 횟수), `days_since_injury` (마지막 이상 후 경과일)  
**방법:** PDF 텍스트 파싱 → 키워드(근육통, 찰과상, 염증 등) 카운팅

### EXP-2 핵심 결론
- 배당은 모델 정확도에 결정적인 피처 (Top-1 35.6% vs 19.5%)
- 배당 없이는 시장보다 정확도가 낮아 독립적 예측 가치 부족
- **전략:** 배당 포함 모델 유지 + 배당 대비 우리 모델이 크게 다른 케이스를 "이상치"로 발견하는 방식이 최적
  - 예: 배당 5위 말을 모델이 1위로 예측 → 잠재적 가치베팅 후보

### EXP-6 결론
- 기수 변경 자체(jockey_changed, jockey_wr_delta)는 배당 제외 모델에서도 거의 개선 없음
- 배당이 이미 기수 변경 효과를 가격에 반영하고 있을 가능성 높음
