## 핵심 발견 사항

### 1. Cold-Start 문제 (긴급 수정 완료)

**문제:** 2026년 말들은 2021-2022 훈련 데이터에 이력이 없어 `_n_starts=0`.  
Cold-start 로직이 `field_avg = 1/N`으로 100% 덮어쓰기 → 모든 말 동일 확률.

**수정 (2026-06-28 완료):** `service.py` cold-start anchor를  
`field_avg` → **역배당 가중 평균 (1/odds 정규화)** 으로 교체.  
결과: 서울 10경주에서 의미 있는 확률 분포 복원, 1순위 적중 40%.

```python
# Before
field_avg = 1.0 / len(probs)

# After  
inv_odds = 1.0 / np.array([max(r["morning_odds"], 1.0) for r in rows])
anchor = inv_odds / inv_odds.sum()
```

### 2. 훈련 데이터 공백 (2023-2025)

현재 크롤 완료: 2021-2022 (2,743경주, 31,095경주결과) + 2026-06-27 (17경주).  
**2023-2025 3년치 데이터가 누락**되어:
- 현역 말들의 최근 성적이 훈련셋에 없음
- 기수/조교사 최근 승률 전혀 반영 안 됨
- 모델이 오래된 말-기수 관계 패턴만 학습

### 3. 제주 경주 완전 flat 예측

제주 2026-06-27 말들: `n_results=1` (전부 오늘 결과만 있음).  
Query `WHERE race_date < today`로 보면 이력 0 → 역배당 fallback으로도 OK.  
하지만 제주는 경주마 순환이 빠르고 서울/부산과 계절 특성이 달라  
별도 모델 (현재 분리되어 있음) 유지가 올바른 방향.
